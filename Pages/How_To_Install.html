  • Tutorials

    • How to Update
      • └ Go to the Downloads Page by clicking the Downloads button on this Page or in the ToolBox go to: Settings > Update Rebugger ToolBox > Download Page └ Download the Latest Stable Or Dev Build └ Download the file to /dev_hdd0/packages or /dev_hdd0/dev_usb000 (number might be different for you) └ Then if your on HEN/HFW Download the HEN Patch to go with it! └ After you've downloaded it go back to Rebugger ToolBox and go to: Settings > Delete Rebugger ToolBox > Completely Remove Rebugger ToolBox └ Then after its deleted restart your Console and then go to: Package Manager > Install Package Files > (PS3 System Storage or Standard) └ And Install Rebugger.Toolbox.Installer_CFW.pkg └ And then IF your on HEN/HFW Install Rebugger.Toolbox.Patch_HEN.pkg └ Then restart your PS3 and then your done!
    • How to Install
      • └ Download the Latest Stable Or Dev Build from the Downloads Page or from GitHub [Link] └ Make sure you download the Fixes too: Rebugger_Toolbox_Fixes_Mount_dev_blind_First.pkg (Both files combined) └ If your on PS3 Download the files to /dev_hdd0/packages or /dev_hdd0/dev_usb000 (number might be different for you) └ If your on PC Download the files like you would any other file and then put them on the root of your USB or move them over to your PS3 using FileZilla └ Put them in one of these path locations: /dev_hdd0/packages or USB/FileName └ On your PS3 go to: WebMAN Games > WebMAN Setup > Enable /dev_blind └ and then Once the files are in your USB or on the PS3 Use your Package Manager to Install them: Package Manager > Install Package Files > (PS3 System Storage or Standard) └ First Install: Rebugger_Toolbox_Fixes_Mount_dev_blind_First.pkg (Both files combined) or Rebugger_Toolbox_Plugin_Installer_Mount_dev_blind_First.pkg > Rebugger_Toolbox_Category_Installer_Mount_dev_blind_First.pkg └ And Then Install Rebugger.Toolbox.Installer_CFW.pkg └ Then IF Your on HEN/HFW Install Rebugger.Toolbox.Patch_HEN.pkg └ Then restart your Console and your good to go!, you'll find Rebugger - ToolBox in the PSN/PlayStation Network Category on your XMB!

    Common sense (Errors etc)

    • Read this before trying to contact me and annoy me!
    • Read the How to Install/Update Tutorial First!
    • If your getting a Error (8001003A) when trying to Install its because you haven't Enabled /dev_blind!
    • If you switch or reinstall your PS3s Firmware you will need to reenable /dev_blind and then reinstall the Fixes again or you won't be able to see/access the ToolBox!
