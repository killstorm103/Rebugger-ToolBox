Rebugger - ToolBox: How to Install

  • Tutorials

    • How to unInstal: └ Go into: Rebugger - ToolBox > Settings > Delete Rebugger Toolbox > Completely remove Rebugger Toolbox?
      └ Then Press X on this and wait until you get a notification saying it's been uninstalled or until your ps3s clocks time is updating again and don't press Anything during this process!
      └ or using mmCM or FileZilla go to: /dev_hdd0/game
      └ and find Rebugger_Tool and delete that folder, after deleting it restart your PS3
      └ The Fixes for Rebugger - ToolBox will still be on your console if you want to remove them reinstall your PS3's Firmware!
    • How to Update: └ Go to the Downloads Page by clicking the Downloads button on this Page or in the ToolBox go to: Settings > Update Rebugger ToolBox > Download Page
      └ Download the Latest Stable Or Dev Build
      └ Download the file to /dev_hdd0/packages or /dev_hdd0/dev_usb000 (number might be different for you)
      └ Then if you're on HEN/HFW Download the HEN Patch to go with it!
      └ After you've downloaded it go back to Rebugger ToolBox and go to: Settings > Delete Rebugger ToolBox > Completely Remove Rebugger ToolBox
      └ Then after it's deleted restart your Console and then go to: Package Manager > Install Package Files > (PS3 System Storage or Standard)
      └ And Install Rebugger.Toolbox.Installer_CFW.pkg
      └ And then IF you're on HEN/HFW Install Rebugger.Toolbox.Patch_HEN.pkg
      └ Then restart your PS3 and you're done!
    • How to Install: └ Download the Latest Stable Or Dev Build from the Downloads Page or from GitHub [Link]
      └ Make sure you download the Fixes too: Rebugger_Toolbox_Fixes_Mount_dev_blind_First.pkg (Both files combined)
      └ If you're on PS3 Download the files to /dev_hdd0/packages or /dev_hdd0/dev_usb000 (number might be different for you)
      └ If you're on PC Download the files like you would any other file and then put them on the root of your USB or move them over to your PS3 using FileZilla
      └ Put them in one of these path locations: /dev_hdd0/packages or USB/FileName
      └ On your PS3 go to: WebMAN Games > WebMAN Setup > Enable /dev_blind
      └ Once the files are on your USB or PS3, use your Package Manager to Install them: Package Manager > Install Package Files > (PS3 System Storage or Standard)
      └ First Install: Rebugger_Toolbox_Fixes_Mount_dev_blind_First.pkg (Both files combined) or Rebugger_Toolbox_Plugin_Installer_Mount_dev_blind_First.pkg > Rebugger_Toolbox_Category_Installer_Mount_dev_blind_First.pkg
      └ And Then Install Rebugger.Toolbox.Installer_CFW.pkg
      └ Then IF you're on HEN/HFW Install Rebugger.Toolbox.Patch_HEN.pkg
      └ Then restart your Console – you'll find Rebugger - ToolBox in the PSN/PlayStation Network Category on your XMB!

    Common sense (Errors etc)

    • Important Notes: └ Read this before trying to contact me and annoy me!
      └ Read the How to Uninstall/Install/Update Tutorial First!
      └ If you're getting a Error (8001003A) when trying to Install, it's because you haven't Enabled /dev_blind!
      └ If a Mod/Cheat Installer or Remover stops working try: uninstalling the toolbox and reinstalling it if that doesn't work uninstall it again and reinstall your firmware and then reinstall the toolbox!
      └ If you switch or reinstall your PS3's Firmware, you will need to reenable /dev_blind and then reinstall the Fixes again or you won't be able to see/access the ToolBox!
      └ Rebugger_Toolbox_Fixes_Mount_dev_blind_First.pkg (Both files combined) or Rebugger_Toolbox_Plugin_Installer_Mount_dev_blind_First.pkg > Rebugger_Toolbox_Category_Installer_Mount_dev_blind_First.pkg
