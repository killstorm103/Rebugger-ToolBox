  • Information

    • WebMAN Mod
      └ How to manually delete WebMAN when it's corrupted: use mmCM or FileZilla to delete it. You will need to put your wm_ignore.txt back in: /dev_hdd0/tmp/wm_res after reinstalling WebMAN Mod. Uninstalling Tutorial [Link]
      └ You can reinstall wm_ignore.txt from within my ToolBox. After installing wm_ignore.txt, go into: webMAN Games > webMAN Setup > Refresh webMAN Games & XMB
    • Control Console Api (CCApi) (CFW Only)
      └ DO NOT Install this at all – it's broken and unstable as fuck! Use: ProDG Target Manager for PS3 (TMAPi) instead! (DEX CFW & DEV Kit PS3s Only)
      └ Installed on your PC/Laptop Only!
    • PKGi PS3 Setup
      └ Install the config files from within my ToolBox, then sign into PSN, go into: Account Management > System Activation > PS3 System > (Game & Video) > Activate System. Open PKGi PS3, press [Select] and go to: Refresh...
    • How to Install Game Mods/Cheats
      └ Create a backup of your game's EBOOT.BIN, then replace the eboot with the modded one. Install the mod files in /dev_hdd0/tmp if there are any. .sprx files usually go in /dev_hdd0/tmp, but some go in tmp/ModName or ModName/GameName.
      └ Make sure you put your licence key in your key.txt or licence.txt if it is a Premium Mod/Cheat.
